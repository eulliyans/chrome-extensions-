# Quick Autofill

### A Smart Form Assistant by EULLIYAN'S

Fill smarter. Save time.

Quick Autofill helps users complete online forms faster by saving basic personal information and automatically filling matching empty fields.

## Features

- Save basic personal information
- One-click form filling
- Smart field detection
- Fill empty fields without overwriting existing information
- Support for common registration and contact forms
- Simple and lightweight interface
- Privacy-focused design

## How It Works

1. Save your personal information.
2. Open a website with a form.
3. Click **Fill this page**.
4. Quick Autofill fills matching empty fields.

## Current Information Supported

- Full Name
- Email
- Phone
- Address
- City
- Postal Code
- Country

## Privacy

Quick Autofill stores saved information in Chrome's local storage.

- Does not intentionally overwrite fields containing information.
- Skips password fields.
- Does not store passwords or payment card numbers.
- User controls the information saved in the extension.
